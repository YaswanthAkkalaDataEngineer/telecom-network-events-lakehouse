# Source-to-Target Mapping

| Source | Main transformations | Target |
|---|---|---|
| CDR | Parse timestamps, deduplicate, flag dropped and poor-quality calls | Daily tower KPIs |
| Network events | Flag congestion and calculate availability/utilization metrics | Daily tower KPIs |
| Subscriber activity | Standardize usage and device activity | Subscriber analytics extension |
| Cell towers | Reference and relationship consistency | KPI enrichment |
| Service tickets | Open-ticket and resolution analysis | Operations extension |
| Outages | Duration and affected-subscriber analysis | Reliability extension |
